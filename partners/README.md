# 박람회 참여기업 관리대장

SCEWC 같은 해외 AI·스마트시티 박람회에 나간 참여기업(2025년~, 약 8곳)의 계약·고용 실적과
면담·기업행사·기부·네트워킹 기록을 한곳에서 관리하는 도구입니다. 서버와 설치가 필요 없고
HTML 파일 두 개로 동작합니다.

| 파일 | 누가 쓰나 | 하는 일 |
|---|---|---|
| `index.html` | 시 담당자 | 관리대장: 기업 정보, 분기 실적, 활동기록, 박람회 이력, 백업·엑셀·공개요약 |
| `submit.html` | 참여기업 | 분기 실적 제출양식: 입력하면 **제출 파일(.json)** 이 만들어지고, 기업은 이 파일을 담당자에게 보냄 |

## 정보 보호 설계

- **데이터는 저장소(GitHub)에 들어가지 않습니다.** 이 폴더에는 프로그램만 있습니다. 이 저장소는
  공개 사이트로 배포되므로, 백업·제출 파일(`*.json`)은 `.gitignore` 로 막아 두었습니다.
- 관리대장 데이터는 **담당자 PC의 브라우저에만** 저장되며, 암호를 설정하면 **AES-256으로 암호화**됩니다
  (PBKDF2 25만 회). 30분 동안 쓰지 않으면 자동으로 잠깁니다.
- 백업 파일도 같은 암호로 암호화됩니다. **암호를 잊으면 복구할 수 없습니다.**
- 항목마다 공개 범위가 정해져 있습니다.
  - **공개**: 기업명·분야·제품·특허/인증. 홍보자료에 써도 되는 정보
  - **내부**: 계약·고용 실적, 대표자, 소재지
  - **대외비**: 사업자번호·담당자 연락처·매출·투자액·내부 메모. 화면에서 가려지고, 엑셀로 내보낼 때도 기본적으로 빠짐
- **공개용 요약**에는 합계만 나옵니다. 기업명과 개별 실적은 기업이 제출양식에서 **공개에 동의한 경우에만** 나옵니다.
- 기업은 제출양식만 받으므로 **다른 기업의 정보를 볼 수 없습니다.** 제출양식은 입력 내용을
  어디로도 전송하지 않고 파일만 만듭니다.

## 쓰는 법

1. `index.html` 을 크롬이나 엣지로 엽니다. 내부망 PC라면 폴더째 복사해 두고 더블클릭해도 됩니다.
   처음 열 때 암호를 정합니다.
2. **기업** 탭에서 참여기업을 등록하고, **박람회** 탭에서 SCEWC 등 참가 이력에 기업을 연결합니다.
3. 분기마다 **현황** 탭의 「미제출 기업 → 요청 문구 복사」로 기업별 전용 링크를 메일이나 메신저로 보냅니다.
4. 기업이 보낸 파일은 **실적 → 기업 제출파일 가져오기**로 여러 개를 한 번에 불러옵니다.
   기업 소식(행사·기부 등)은 활동기록으로 들어갑니다.
5. 면담·현장방문·기업행사·기부·네트워킹은 **활동기록**에 바로 남기고, 후속조치는 체크박스로 관리합니다.
6. **자료관리 → 백업 파일 저장**을 주 1회 이상 하고, 저장한 파일을 내부 공유폴더에 보관합니다.
   다른 PC에서는 「백업 파일 불러오기」로 이어서 쓸 수 있습니다.

### 제출양식을 기업에 주는 방법

- `submit.html` 을 기업이 열 수 있는 곳에 둡니다. 이 저장소의 GitHub Pages
  (`…/partners/submit.html`)에 둬도 됩니다. 양식은 입력 내용을 전송하지 않아서, 공개된 곳에 있어도 안전합니다.
- 그 주소를 관리대장의 **자료관리 → 제출양식 주소**에 넣으면, 이후 복사하는 링크에 기업명·분기가 미리 채워집니다.
- 웹에 둘 수 없으면 `submit.html` 파일을 메일에 첨부해 보내도 됩니다. 기업이 파일을 열어 입력하면 됩니다.

## 알아둘 점

- 같은 PC라도 브라우저(크롬·엣지)가 다르면 데이터가 따로 저장됩니다. 한 브라우저로 정해서 쓰세요.
- 브라우저의 「인터넷 사용 기록 삭제」에서 쿠키·사이트 데이터를 지우면 관리대장 데이터도 지워집니다.
  **백업이 유일한 복구 수단**입니다.
- 여러 담당자가 동시에 함께 편집하는 기능은 없습니다. 담당자 한 명이 관리하고, 백업 파일로 인수인계합니다.
