# 천안 일반 언론 뉴스

`python scripts/collect_local_news.py`로 `data/local-news.json`을 갱신합니다.
표준 Python만 필요하며 API 키와 AI 요약 비용이 없습니다.

기존 사이트의 ‘천안 뉴스’ 탭에 기간·언론사·제목·주제 필터, 읽음 표시,
원문 연결과 매체별 검색 현황을 제공합니다. 본문·사진은 복제하지 않습니다.

수집은 Google 뉴스 검색 RSS 기반입니다. 다음 검색 결과나 언론사 홈페이지를
직접 수집하는 방식은 아닙니다. 제목에 천안이 없거나 검색에 등록되지 않은
기사는 누락됩니다. 매체별 0건은 미발행을 의미하지 않습니다.
최근 7일을 재조회하고 30일 보관합니다. 같은 매체·같은 제목은 중복 제거합니다.
분류는 제목 키워드 방식이며 오분류될 수 있습니다.

`.github/workflows/local-news.yml`이 배포되면 매일 06:17 KST 예약 실행 및
수동 실행이 가능합니다. GitHub 예약 실행은 지연될 수 있습니다.
수집 실패 시 이전 기사와 실패 상태를 저장합니다. 모든 조회가 실패하면 실행도 실패합니다.

로컬 미리보기: `python -m http.server 8765 --bind 127.0.0.1` 실행 후
http://127.0.0.1:8765 에서 ‘천안 뉴스’ 탭을 선택합니다.
